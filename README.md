## GitHub Pages

This repository is intended to be published via **Settings → Pages → Deploy from a branch → main → /(root)**. The expected site URL is https://shosuke-kinoshita-home.github.io/ (verify after enabling GitHub Pages).

## Security boundary

**Do not add** LifeOS source repositories, recordings, transcripts, journals, OAuth client secrets, access/refresh tokens, environment files, internal service URLs, logs, or local deployment config to this public repository. The website does not host or operate the Voice Processor itself.

## OAuth notes

Google OAuth branding may require independent domain ownership verification; hosting on github.io does not guarantee that Google's authorized-domain validation will accept the domain. Review the privacy policy against actual running behavior and make any required clarifications before submitting the app for verification.
